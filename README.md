I have chosen hu and liu's opinion lexicon for the etra credit part

preprocess.py
load_data() gets the raw reviews from the folders and assigns labels.
preprocess_text() turns each raw review into tokens and modifies tokens to handle negation

feature_extractor.py
handles the conversion of the tokenized reviews into numerical features for the classifier.implements the different configurations required in task 1, including frequency, binary, function-word removal, and negation features. CountVectorizer is used to create the document-term matrices, with sparse matrices used to save memory. also supports the extra-credit config, where positive and negative word counts from the Hu and Liu opinion lexicon are added as extra features.
extract_features() func returns the training features, test features, and the fitted vectorizer for use by the classifier.

classifiers.py
implementations of Naive Bayes and Logistic Regression classifiers. Naive Bayes classifier calculates class priors and word likelihoods from the training data. I use Laplace smoothing so unseen words dont get zero probability. log probabilities are used in Naive Bayes to avoid problems with multiplying very small probabilities. classifier can work with both normal word frequencies and binary features.
Logistic Regression classifier starts with zero weights and learns them using stochastic gradient descent. it uses the sigmoid function to convert the model output into a probability between 0 and 1. The weights and bias are updated after each training example based on the prediction error.
both classifiers work with the sparse feature matrices generated by features_extractor.py.
The predict() functions then use the learned parameters to predict whether each review is positive or negative.

main.py
loads the review dataset and splits it into 80% training and 20% testing data. for each of the 8 feature configurations, it tokenizes the reviews and extracts the required features. it trains and tests both my custom Naive Bayes and Logistic Regression classifiers. it prints the confusion matrix and classification metrics for each classifier and configuration.
it also saves some false positives and false negatives into fumbles.txt for error analysis.
